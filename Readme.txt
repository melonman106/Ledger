================================================================================
  THE LEDGER — TV & Movie Index (Cloudflare Worker)
================================================================================

A single-file Cloudflare Worker that serves "The Ledger," a newspaper-themed
TV show and movie catalog with streaming playback via VIDEASY embeds. It uses
TMDB (The Movie Database) for metadata and Clerk for authentication.

--------------------------------------------------------------------------------
  1. OVERVIEW
--------------------------------------------------------------------------------

The Ledger is a Cloudflare Worker that returns server-rendered HTML pages for
browsing and watching TV shows and movies. There is no client-side framework —
each page is an HTML string generated by the Worker, with client-side
JavaScript handling interactivity (fetching data, rendering grids, managing
the video player, etc.).

The design follows a vintage newspaper aesthetic: serif typography, a warm
"paper" background, monospace metadata labels, and a muted accent color.

This is the TV & Movie edition. A separate anime & manga edition exists with
AniList/Anivexa/MangaDex integrations.


--------------------------------------------------------------------------------
  2. ROUTES
--------------------------------------------------------------------------------

  Route                          Method   Description
  -----------------------------  --------  ---------------------------------------
  /                              GET       Index/home page — browse categories
  /index.html                    GET       Alias for /
  /detail/:id                    GET       Detail page (auto-detects tv or movie)
  /detail/tv/:id                 GET       Detail page for a TV show
  /detail/movie/:id              GET       Detail page for a movie
  /watch/tv/:id                  GET       Watch page for a TV show
  /watch/movie/:id               GET       Watch page for a movie
  /api/tmdb/*                     GET       Proxy to the TMDB API (injects API key)
  (any other path)               GET       Returns 404 Not Found

  :id must be a numeric TMDB media ID (e.g., /detail/tv/1396).

  Note: /watch requires an explicit media type (tv or movie) in the URL.
  /detail can auto-detect the type if only a numeric ID is provided (tries
  movie first, then TV).


--------------------------------------------------------------------------------
  3. ENVIRONMENT VARIABLES
--------------------------------------------------------------------------------

  Variable                  Required  Default
  ------------------------  --------  ----------------------------------------
  CLERK_PUBLISHABLE_KEY     Yes       (none)
  CLERK_FRONTEND_API_URL   Yes       (none)
  TMDB_API_KEY             Yes       (none)

  Set these in the Workers dashboard under Settings > Variables, or in your
  wrangler.toml under [vars].

  Example (wrangler.toml):
    name = "the-ledger-tv"
    main = "worker.js"
    compatibility_date = "2024-01-01"

    [vars]
    CLERK_PUBLISHABLE_KEY = "pk_test_xxxxxxxxxxxxxxxx"
    CLERK_FRONTEND_API_URL = "https://your-clerk-frontend.clerk.accounts.dev"
    TMDB_API_KEY = "your_tmdb_v3_api_key"

  The TMDB API key is injected server-side by the proxy, so it is never
  exposed to the client.

--------------------------------------------------------------------------------
  5. FEATURES
--------------------------------------------------------------------------------

  5.1  Index Page (/)
  ---------------------------------------------------------------------------

  The landing page presents a tabbed navigation bar with seven modes:

    - Top TV          — Top rated TV shows (TMDB /tv/top_rated)
    - Top Films       — Top rated movies (TMDB /movie/top_rated)
    - Popular TV      — Popular TV shows (TMDB /tv/popular)
    - Popular Films   — Popular movies (TMDB /movie/popular)
    - Trending        — Trending this week across TV & film
                        (TMDB /trending/all/week)
    - In Theaters     — Movies currently in theaters
                        (TMDB /movie/now_playing)
    - Search          — Search TMDB by title (TV or Movie toggle)

  Each entry shows a poster image, rank number, title, type (TV/Film),
  year, and score. Clicking an entry navigates to /detail/:type/:id.

  5.2  Detail Page (/detail/[tv|movie]/:id)
  ---------------------------------------------------------------------------

  Shows full metadata for a single TV show or movie:

    - Poster image, title, tagline
    - Score (out of 10), type, seasons/episodes (TV) or runtime (movie),
      status, year
    - Genres
    - Production studio(s)
    - Synopsis (TMDB overview)
    - "Watch Now" button linking to /watch/:type/:id

  When accessed via /detail/:id (no type), the page auto-detects by trying
  the movie endpoint first, then falling back to TV.

  5.3  Watch Page (/watch/[tv|movie]/:id)
  ---------------------------------------------------------------------------

  A streaming watch page using VIDEASY iframe embeds:

    - VIDEASY embed player (https://player.videasy.net)
    - Loading overlay with spinner while the iframe loads
    - For TV shows:
        - Season selector dropdown (from TMDB season data)
        - Episode grid (clickable episode number buttons)
        - Auto-loads the first episode of the first season
        - "Next Episode" autoplay enabled via VIDEASY params
        - Episode selector overlay enabled
    - For movies:
        - Loads the movie player immediately
    - "Now Playing" sidebar card showing current episode/title and source
    - Progress bar with current time / duration / percentage
    - Back link to the detail page

  VIDEASY embed URL format:
    TV:   https://player.videasy.net/tv/:id/:season/:episode?color=a63d2f&nextEpisode=true&episodeSelector=true&autoplayNextEpisode=true&overlay=true
    Movie: https://player.videasy.net/movie/:id?color=a63d2f&overlay=true

  The accent color (a63d2f) matches the newspaper theme.

  5.4  TMDB API Proxy (/api/tmdb/*)
  ---------------------------------------------------------------------------

  Proxies requests to the TMDB v3 API. Strips the /api/tmdb prefix and
  forwards the remaining path + query string to
  https://api.themoviedb.org/3. The TMDB API key is appended server-side
  as the api_key query parameter, keeping it secret.

  Responses are cached in the Cloudflare cache for 5 minutes
  (max-age=300). A Cache HIT/MISS header is included.

  Example:
    /api/tmdb/tv/top_rated?page=1
      ->  https://api.themoviedb.org/3/tv/top_rated?page=1&api_key=YOUR_KEY


--------------------------------------------------------------------------------
  6. AUTHENTICATION
--------------------------------------------------------------------------------

  Authentication is handled by Clerk. All pages require sign-in before
  content is revealed.

  Flow:
    1. The Worker injects the Clerk JS SDK script using
       CLERK_PUBLISHABLE_KEY and CLERK_FRONTEND_API_URL.
    2. On page load, a polling interval detects when window.Clerk becomes
       available, then initializes it via Clerk.load().
    3. If signed out, an "auth gate" overlay is shown with Sign In / Sign
       Up buttons. The main app content is hidden.
    4. If signed in, the auth gate is hidden, the app content is revealed,
       and the header shows the user's name with a Sign Out button.
    5. Once authenticated, the page-specific onAuthenticated() function
       is called to load content.

  The Clerk publishable key and frontend API URL are injected into the HTML
  at render time, so they must be set as environment variables.


--------------------------------------------------------------------------------
  7. CACHING
--------------------------------------------------------------------------------

  The /api/tmdb/* proxy uses the Cloudflare Cache API (caches.default) to
  cache TMDB API responses for 5 minutes. This reduces latency and avoids
  hitting TMDB rate limits.

  Cached responses include:
    - X-Cache: HIT  (served from cache)
    - X-Cache: MISS (fetched from origin, then cached)


--------------------------------------------------------------------------------
  8. STREAMING (VIDEASY)
--------------------------------------------------------------------------------

  Video playback is handled entirely by VIDEASY iframe embeds. No stream
  proxy is needed — the iframe loads directly from
  https://player.videasy.net.

  VIDEASY provides:
    - Multi-source playback within the embed
    - Next episode autoplay (TV)
    - Episode selector overlay (TV)
    - Customizable accent color

  The Worker does not handle video streams, HLS, or download links. All
  playback is delegated to the VIDEASY embed.


--------------------------------------------------------------------------------
  9. PROGRESS TRACKING
--------------------------------------------------------------------------------

  The watch page listens for postMessage events from the VIDEASY iframe.
  VIDEASY sends JSON messages containing:
    - id, type, progress (0-100), timestamp (current time), duration,
      season, episode

  The watch page:
    1. Updates the progress bar and time display in real time.
    2. Saves progress to localStorage with a key like:
         ledger-progress-tv-1396-1-1  (for TV)
         ledger-progress-movie-550    (for movies)
       The saved object contains: currentTime, duration, progress, and
       a timestamp (Date.now()).

  Progress is stored locally per user/device. There is no server-side
  progress tracking.


--------------------------------------------------------------------------------
  10. DEPLOYMENT
--------------------------------------------------------------------------------

  This is a single-file Cloudflare Worker. To deploy:

  Option A — Wrangler CLI:
    1. Install Wrangler:  npm install -g wrangler
    2. Save the worker code to a file (e.g., worker.js).
    3. Create wrangler.toml:

       name = "the-ledger-tv"
       main = "worker.js"
       compatibility_date = "2024-01-01"

       [vars]
       CLERK_PUBLISHABLE_KEY = "pk_test_xxxxx"
       CLERK_FRONTEND_API_URL = "https://your-clerk.clerk.accounts.dev"
       TMDB_API_KEY = "your_tmdb_v3_api_key"

    4. Deploy:  wrangler deploy

  Option B — Dashboard:
    1. Go to Workers & Pages in the Cloudflare dashboard.
    2. Create a new Worker.
    3. Paste the worker code into the editor.
    4. Under Settings > Variables, add the environment variables listed in
       section 3.
    5. Save and deploy.

  Getting a TMDB API key:
    1. Create a free account at https://www.themoviedb.org/
    2. Go to Settings > API
    3. Request an API key (v3)
    4. Use the API Key (not the Read Access Token) as TMDB_API_KEY.
