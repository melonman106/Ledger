================================================================================
  THE LEDGER — Anime & Manga Index (Cloudflare Worker)
================================================================================

A single-file Cloudflare Worker that serves "The Ledger," a newspaper-themed
anime and manga catalog with streaming and reading capabilities. It combines
AniList metadata, an Anivexa streaming API, MangaDex chapter data, and Clerk
authentication into one server-rendered application.

--------------------------------------------------------------------------------
  1. OVERVIEW
--------------------------------------------------------------------------------

The Ledger is a Cloudflare Worker that returns server-rendered HTML pages for
browsing, watching, and reading anime and manga. There is no client-side
framework — each page is an HTML string generated by the Worker, with
client-side JavaScript handling interactivity (fetching data, rendering grids,
managing the video player, etc.).

The design follows a vintage newspaper aesthetic: serif typography, a warm
"paper" background, monospace metadata labels, and a muted accent color.


--------------------------------------------------------------------------------
  2. ROUTES
--------------------------------------------------------------------------------

  Route                   Method   Description
  ---------------------  --------  ------------------------------------------
  /                      GET       Index/home page — browse categories
  /index.html            GET       Alias for /
  /detail/:anilistId     GET       Detail page for a specific anime or manga
  /watch/:anilistId      GET       Streaming watch page for an anime
  /read/:anilistId       GET       Manga reader page
  /api/*                 GET       Proxy to the Anivexa streaming API
  /md/*                  GET       Proxy to the MangaDex API
  (any other path)       GET       Returns 404 Not Found

  :anilistId must be a numeric AniList media ID (e.g., /detail/21).


--------------------------------------------------------------------------------
  3. ENVIRONMENT VARIABLES
--------------------------------------------------------------------------------

  Variable                  Required  Default
  ------------------------  --------  ----------------------------------------
  CLERK_PUBLISHABLE_KEY     Yes       (none)
  CLERK_FRONTEND_API_URL   Yes       (none)
  ANIVEXA_API_URL           No        https://anivexa-api-gubc.onrender.com
  STREAM_PROXY_URL         No        https://stream-proxy.muldera.workers.dev/?url=

  Set these in the Workers dashboard under Settings > Variables, or in your
  wrangler.toml / wrangler.jsonc under [vars] / "vars".

  Example (wrangler.toml):
    [vars]
    CLERK_PUBLISHABLE_KEY = "pk_test_xxxxxxxxxxxxxxxx"
    CLERK_FRONTEND_API_URL = "https://your-clerk-frontend.clerk.accounts.dev"
    ANIVEXA_API_URL = "https://anivexa-api-gubc.onrender.com"
    STREAM_PROXY_URL = "https://stream-proxy.muldera.workers.dev/?url="

--------------------------------------------------------------------------------
  5. FEATURES
--------------------------------------------------------------------------------

  5.1  Index Page (/)
  ---------------------------------------------------------------------------

  The landing page presents a tabbed navigation bar with seven modes:

    - Top Ten        — Top 10 anime by score (AniList)
    - Popular        — Top 20 anime by popularity
    - Random Pull    — A random page of popular anime
    - This Season    — Currently airing anime (filterable by season & year)
    - On the Horizon — Upcoming next-season anime
    - Top Manga      — Top 20 manga by score
    - Search         — Search AniList by title (anime or manga)

  Each entry shows a cover image, rank number, title, format, episode/chapter
  count, and score. Clicking an entry navigates to /detail/:id.

  5.2  Detail Page (/detail/:anilistId)
  ---------------------------------------------------------------------------

  Shows full metadata for a single anime or manga:

    - Cover image, title (English/Romaji), native title
    - Score, format, episode/chapter count, status, season/year
    - Genres, studio
    - Synopsis (HTML stripped from AniList description)
    - "Watch Now" button (for anime) or "Read Now" button (for manga)

  5.3  Watch Page (/watch/:anilistId)
  ---------------------------------------------------------------------------

  A full anime streaming player with:

    - HLS.js-based video player (falls back to native HLS on Safari)
    - Embed player support for iframe-type streams
    - Multiple provider tabs (allmanga, reanime, anikoto, animegg, anineko,
      anidbapp, 2dhive, animenosub, anizone, anibd, senshi, kaa, animedunya)
    - Sub / Dub audio toggle
    - Episode grid with filler marking
    - Server selection (multiple streams per episode)
    - Skip Intro / Skip Outro buttons (when timestamp data is available)
    - Subtitle track listing
    - Download link listing
    - "Now Playing" info card
    - Stream proxying via STREAM_PROXY_URL for CORS

  Episode and stream data are fetched from the Anivexa API through the /api
  proxy. The API server may sleep (e.g., on Render free tier); the UI shows a
  "waking up" message and auto-retries after 10 seconds on HTTP 502.

  5.4  Read Page (/read/:anilistId)
  ---------------------------------------------------------------------------

  A manga reader with:

    - Automatic MangaDex lookup by AniList title (with fallback searches)
    - Chapter list with scanlation group names
    - English chapter filtering (falls back to all languages if none)
    - Three reading modes: Single page, Double page, Vertical scroll
    - Page navigation (buttons + arrow keys)
    - Chapter navigation (prev/next chapter)
    - Fullscreen mode
    - Page images proxied through STREAM_PROXY_URL for CORS

  5.5  API Proxy (/api/*)
  ---------------------------------------------------------------------------

  Proxies requests to the Anivexa API. Strips the /api prefix and forwards
  the remaining path + query string. Responses are cached in the Cloudflare
  cache for 5 minutes (max-age=300). A Cache HIT/MISS header is included.

  Example:
    /api/episodes/21  ->  https://anivexa-api-gubc.onrender.com/episodes/21

  5.6  MangaDex Proxy (/md/*)
  ---------------------------------------------------------------------------

  Proxies requests to the MangaDex API (https://api.mangadex.org). Strips the
  /md prefix and forwards the remaining path + query string. Returns a
  formatted JSON error if MangaDex is unavailable or returns non-JSON.

  Example:
    /md/manga?title=Berserk  ->  https://api.mangadex.org/manga?title=Berserk


--------------------------------------------------------------------------------
  6. AUTHENTICATION
--------------------------------------------------------------------------------

  Authentication is handled by Clerk. All pages require sign-in before content
  is revealed.

  Flow:
    1. The Worker injects the Clerk JS SDK script using
       CLERK_PUBLISHABLE_KEY and CLERK_FRONTEND_API_URL.
    2. On page load, the Clerk SDK initializes and checks user state.
    3. If signed out, an "auth gate" overlay is shown with Sign In / Sign Up
       buttons. The main app content is hidden.
    4. If signed in, the auth gate is hidden, the app content is revealed,
       and the header shows the user's name with a Sign Out button.
    5. A polling interval detects when window.Clerk becomes available, then
       initializes it.

  The Clerk publishable key and frontend API URL are injected into the HTML
  at render time, so they must be set as environment variables.


--------------------------------------------------------------------------------
  7. CACHING
--------------------------------------------------------------------------------

  The /api/* proxy uses the Cloudflare Cache API (caches.default) to cache
  Anivexa API responses for 5 minutes. This reduces latency and avoids
  hitting the Anivexa API on every request.

  Cached responses include:
    - X-Cache: HIT  (served from cache)
    - X-Cache: MISS (fetched from origin, then cached)

  MangaDex proxy responses are not cached.


--------------------------------------------------------------------------------
  8. DEPLOYMENT
--------------------------------------------------------------------------------

  This is a single-file Cloudflare Worker. To deploy:

  Option A — Wrangler CLI:
    1. Install Wrangler:  npm install -g wrangler
    2. Save the worker code to a file (e.g., worker.js).
    3. Create wrangler.toml:

       name = "the-ledger"
       main = "worker.js"
       compatibility_date = "2024-01-01"

       [vars]
       CLERK_PUBLISHABLE_KEY = "pk_test_xxxxx"
       CLERK_FRONTEND_API_URL = "https://your-clerk.clerk.accounts.dev"
       ANIVEXA_API_URL = "https://anivexa-api-gubc.onrender.com"
       STREAM_PROXY_URL = "https://stream-proxy.muldera.workers.dev/?url="

    4. Deploy:  wrangler deploy

  Option B — Dashboard:
    1. Go to Workers & Pages in the Cloudflare dashboard.
    2. Create a new Worker.
    3. Paste the worker code into the editor.
    4. Under Settings > Variables, add the environment variables listed in
       section 3.
    5. Save and deploy.

  Note: If you are using the stream proxy and Anivexa API defaults, make sure
  those services are running and accessible. The Anivexa API on Render's free
  tier may sleep after inactivity — the first request can take up to 30
  seconds to wake it.
